## What is a `.github` Organization Repository?

GitHub uses a repository named `.github` at the organization level to store default health files and configurations that apply to all repositories within the organization. This allows for centralized management of:
*   Organization Profiles (`profile/README.md`)
*   Default Issue and Pull Request Templates
*   Default Code of Conduct and Contributing Guidelines
*   Default Security Policies

For more information, see the [GitHub documentation on creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
