# Organization Profile Management

This directory contains the public-facing profile documentation for the Jules-Vernsion-Control organization.

## Key Files

*   **`README.md`**: This is the organization's public profile page. Any modifications to this file should be made carefully, as it directly impacts the organization's public presentation.

## Guidelines for Agents

*   When updating the profile, ensure the content reflects the mission of Jules-Vernsion-Control as a quarantined sandbox and experimental space for autonomous coding agents.
*   Maintain the markdown formatting and tone of existing content.
*   Do not remove the experimental warnings unless explicitly directed to do so.
*   Always verify your changes with `cat profile/README.md` or similar commands before committing.
